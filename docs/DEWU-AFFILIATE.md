# 得物带货与挂链说明

## 得物有没有免费 API 自动挂链？

**没有**面向普通创作者、类似「淘宝联盟」的公开免费 CPS API。

| 渠道 | 适用谁 | 能否自动挂链 |
|------|--------|--------------|
| [得物开放平台](https://open.dewu.com) | 入驻商家 / ISV | 否。订单、发货、库存，非创作者推广 |
| 第三方爬虫/聚合 API | — | **不建议**。合规与封号风险 |
| 得物 App 分享 + 创作者能力 | 副业 / 达人 | **是**。手动复制链接与主图 |

Hype-Forge **不会**爬取得物商品库，**不会**自动抓取商品链接页面，**不会**生成未授权推广短链。

Step3 使用 **一大段粘贴框** 存放从 App 复制的标题/规格/卖点/评价；配合 **多图**（首张主图）与 **一个商品链接**（仅帮助 AI 理解 SKU，不写入右栏发帖正文）。好物链接在得物社区发帖时自行粘贴。

## 推荐变现 SOP

1. 在 Hype-Forge 点 **Scan 得物热点** 或 **爆款线索**，得到搜索方向。
2. 打开得物 App，用关键词搜商品，选高互动款。
3. **保存商品主图**到相册，在本工具上传。
4. 得物商品页 **分享** → 链接粘贴到 Step3 **商品链接**（可选）；好物链发帖时再贴。
5. **Execute** → 复制中栏 **豆包** 提示词出图（或高级区 FLUX）。
6. 点 **导出包**，复制文案 + 链接 + 修图清单。
7. 得物社区发帖，核对链接可点开。

## Step3 链接说明（单链接框）

| 字段 | 是什么 | 文案里怎么用 |
|------|--------|----------------|
| **商品链接** | 得物商品页或分享链接 | **不写入**右栏标题/正文/话题；仅给 AI 理解 SKU |

**好物 / 推广链接** 不在表单中生成：Execute 后的右栏仅为三件套，发帖时在得物 App 自行粘贴带货链接。

## 好物链接从哪来？

- 得物 App 内商品分享链接（最通用）
- 若已开通创作者 / 达人 / 机构能力，在官方后台查看是否有专属带货组件
- 无短链时：文案保留「搜索关键词 + 货号」，链接字段用占位，发帖前再补

## Hype-Forge 负责什么？

| 环节 | 本工具 | 你/第三方 |
|------|--------|-----------|
| 热点/爆款情报 | AI 联网归纳线索 | 得物 App 选品验证 |
| 商品图 | 上传识图 | 得物 App 保存图 |
| 修图出图 | 生成 Prompt | 美图 / 醒图 / FLUX |
| 文案 + 话题 | 生成 + Critic | — |
| 链接写入文案 | **不写入**（仅作 AI 理解 SKU 的上下文） | 发帖时在得物 App 自行粘贴 |
| 发帖 | 导出复制 | 得物社区 |

## 商家开放平台（另一条线）

若你是**得物入驻商家**，开放平台可拉 SKU 与订单，与「创作者挂链」不是同一套能力。本仓库默认不对接；若有 `appKey` 可另开模块评估。
